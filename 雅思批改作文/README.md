# 雅思批改作文

零框架、本地运行的 IELTS Writing 静态资料库。

## 打开方式

直接双击 `index.html` 即可使用。

页面会在当前浏览器中记住所选栏目、作文、模板、素材分类和阅读位置，刷新后自动恢复。

## 数据保存

- 内置作文和素材位于 `data.js`。
- 作文编辑结果保存在当前浏览器的本地存储中。
- “导出 JSONL”可下载完整备份，“导入 JSONL”可恢复备份。
- 清除浏览器网站数据前应先导出备份。

## 文件结构

- `index.html`：页面骨架
- `styles.css`：全部样式
- `app.js`：页面渲染、编辑和本地保存
- `data.js`：作文、模板、范文与主题素材

无需本地服务器、Node.js、pnpm 或任何前端依赖。

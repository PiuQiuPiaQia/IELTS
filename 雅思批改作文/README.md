# 雅思批改作文

这是一个只在本机运行的雅思作文批改页面。

## 使用方法

在 macOS 上双击：

`启动雅思批改作文.command`

页面会自动在浏览器中打开。终端窗口需要保持开启；关闭终端窗口后，本地页面会停止运行。

## 数据保存

- 历史作文、编辑内容和删除结果保存在 `data/reviews.jsonl`。
- JSONL 文件第一行是版本信息，之后每一行是一篇作文记录。
- 从旧版本升级时，浏览器中的原有历史会自动迁移一次。
- 页面不会把作文内容发送到在线数据库。
- 清除浏览器网站数据不会删除作文记录。

## 开发命令

```bash
pnpm install
pnpm dev
pnpm build
```

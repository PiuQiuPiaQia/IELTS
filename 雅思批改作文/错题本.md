## 5. 语气与文体 24 处 ⬅️ 一项都不难，但每篇都在丢

**规则：写给机构/经理用正式表达；写给朋友才用缩写和口语词。**

| 当时写的 | 改后 | 场合 |
|---|---|---|
| `But` | `However,` | 正式信 |
| `So` | `Therefore,` | 正式信 |
| `Or` | `Alternatively,` | 正式信 |
| `And` | `In addition,` | 正式信 |
| `Maybe` | `Perhaps` | 正式信 |
| `pretty important` | `very important` | 正式信 |
| `didn't` | `did not` | 正式信 |
| `can't`（两次） | `cannot` | 正式信 |
| `can not` | `cannot`（通常写一个词） | 正式信 |

## 10. 称呼与落款 9 处 ⬅️ 几乎每封都犯

**判断依据只有一条：收信人是谁，而不是谁让你写。**

| 收信人 | 称呼 | 落款 |
|---|---|---|
| 陌生人 / 机构，没给姓名 | `Dear Sir or Madam,` | `Yours faithfully,` |
| 认识的经理 / 客户 / 同事，给了姓名 | `Dear Mr/Ms [Surname],` | `Yours sincerely,` |
| 朋友或熟人 | `Dear [First name],` | `Best wishes,` |

| 当时写的 | 改后 |
|---|---|
| `Yours faithfully,`（已知姓名） | `Yours sincerely,` |
| `Yours sincerely,`（写给朋友） | `Best wishes,` |
| `Your sincerely,`（两次） | `Yours sincerely,` |
| `Yours,`（不知道对方姓名） | `Yours faithfully,` |
| `Sincerely,` | `sincerely,`（落款里不大写） |
| `Dear Sir for Madam,` | `Dear Sir or Madam,` |
| `Dear Sr or Madam,` | `Dear Sir or Madam,` |
| `Mr. Wang` | `Mr Wang`（英式称呼不加点） |

**最高频错配**：`Dear Sir or Madam,` 配 `Yours sincerely,`。记死配对，别混。

## 13. 写得好的句子（抄下来当模板）

- 正式信开头：`I am writing to complain about [产品或服务] that I [购买或使用] on [日期].`
- 礼貌请求：`I would be grateful if you could consider my request and give me some advice about this move.`
- 礼貌询问：`I would be grateful if we could arrange a face-to-face meeting.`
- 结尾：`I look forward to receiving your reply and having this matter resolved soon.`
- 结尾：`Thank you for considering my request.`
- 建议收尾：`I hope that you will consider these suggestions and take action as soon as possible.`
- 提供信息：`Please let me know if you need any further information.`
- 朋友信：`I really hope you can join me.` / `Hope to hear from you soon.`

## 交卷前 60 秒只查这 5 条

1. **拼写**——过一遍上表，尤其 `-ing`、`-tion`、双写辅音。
2. **每个句子有没有动词**，主语和动词单复数对不对。
3. **单数可数名词前有没有 a / an / the**；`advice / information / feedback / work` 后面不加 s。
4. **称呼和落款配对**：Sir or Madam → faithfully；有姓名 → sincerely；朋友 → Best wishes。
5. **正式信里有没有 `can't / don't / I'm / But / So / Or`**——全部换掉。

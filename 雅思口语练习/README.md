# 雅思口语练习

零框架、本地运行的 IELTS Speaking 静态素材库。

## 打开方式

直接双击 `index.html` 即可使用。

页面会在当前浏览器中记住所选栏目、素材、题目、搜索内容和阅读位置，刷新后自动恢复。

## 文件结构

- `index.html`：页面骨架
- `styles.css`：全部样式
- `app.js`：题库读取和页面交互
- `data.js`：Part 1、Part 2、Part 3、5.5 词伙与万能素材

「5.5 词伙」是一页只放词伙的清单：41 条简单词伙分六组（开场表态、连接骨架、内容词块·日常 / 工作 / 人际、时态），每条只有英文和中文，不写介绍、用法和适用场景。数据在 `data.js` 的 `chunks.groups`；旧的 33 条内容词块链保留在 `chunks.families` 里存档，页面不再显示，`covers` 字段仍可用于校验。

无需本地服务器、Node.js、pnpm 或任何前端依赖。
